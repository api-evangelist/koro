# KoRo

KoRo (KoRo Handels GmbH) is a Berlin-based direct-to-consumer food retailer selling nuts, dried fruit, nut butters, snacks, protein products, baking ingredients and drugstore goods in bulk packaging at wholesale-style prices, shipping across Europe from country storefronts in Germany, Austria, Switzerland, France, Italy and the Benelux/EU shop at koro.com. Founded in 2014 and backed by HV Capital and Partech.

**No public API.** KoRo publishes no developer portal, no partner or commerce API, and no API specifications. Its commerce backend is Shopware 6 fronted by a Nuxt storefront on Vercel; the Shopware Store API surface is internal and gated behind per-sales-channel access keys.

KoRo does publish open-source engineering work through the [KoRoHandelsGmbH](https://github.com/KoRoHandelsGmbH) GitHub organization, including a Nitro-based Shopware Store-API proxy and three Shopware 6 build-tooling packages on npm under the `@korodrogerie` scope.
