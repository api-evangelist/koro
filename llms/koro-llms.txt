# KoRo

> KoRo (KoRo Handels GmbH) is a Berlin-based direct-to-consumer food retailer selling nuts, dried fruit, nut butters, snacks, protein products and drugstore goods in bulk packaging at wholesale-style prices across Europe. KoRo publishes no public API, developer portal or API specification; its commerce backend is Shopware 6 behind a Nuxt storefront on Vercel, and its Store-API surface is internal and gated per sales channel. This file was generated by the API Evangelist enrichment pipeline from the KoRo APIs.json profile.

## Storefronts

- [KoRo (EU / Benelux)](https://www.koro.com/): Primary international storefront.
- [KoRo Germany](https://www.korodrogerie.de/): German storefront (korodrogerie.de).
- [KoRo Austria](https://www.koro-shop.at/): Austrian storefront.
- [KoRo Switzerland](https://www.koro-shop.ch/): Swiss storefront.
- [KoRo France](https://www.koro.fr/): French storefront.
- [KoRo Italy](https://www.koro-shop.it/): Italian storefront.

## APIs

- No public API. KoRo does not publish a developer portal, partner API, commerce API or any OpenAPI/AsyncAPI specification. The internal Shopware Store API is reachable only with a per-sales-channel `sw-access-key` that is not issued publicly.

## Open source

- [KoRoHandelsGmbH on GitHub](https://github.com/KoRoHandelsGmbH): KoRo's public engineering organization.
- [store-api-proxy](https://github.com/KoRoHandelsGmbH/store-api-proxy): Nitro-based thin layer over the Shopware Store API, resolving the sales channel from the `sw-access-key` header and using Vercel's data cache.
- [webpack-shopware-dynamic-chunk-splitting-plugin](https://www.npmjs.com/package/@korodrogerie/webpack-shopware-dynamic-chunk-splitting-plugin): Dynamic-import entry points for Shopware 6.5 storefront components.
- [webpack-plugin-mark-as-assets](https://www.npmjs.com/package/@korodrogerie/webpack-plugin-mark-as-assets): Marks Shopware 6 plugin bundles as assets, excluding them from `all.js`.
- [update-koro-plugin](https://www.npmjs.com/package/@korodrogerie/update-koro-plugin): Updates KoRo Shopware plugins from GitHub Actions.
